# 日序

一个适合手机每天使用的本地计划网站。

## 已有功能

- 打开后直接进入标准月历，周一至周日横向排列，下面按周逐行显示
- 日期格子内直接预览当天计划，点击日期查看完整分类计划
- 每个日期格子右上角可直接添加计划
- 内置 2026 年法定节假日、调休上班日，并显示重阳节等传统节日
- 浅蓝白 iOS 风格，日历之外的冗余日期信息全部收起
- 液态玻璃卡片、模糊折射高光和流动渐变背景
- 生活=日出、体育=能量闪电、学习=书页与星芒，使用彩色玻璃图标
- 生活、体育、学习三个计划分区
- 添加时间、备注，标记完成，编辑或删除计划
- 今天用蓝色选中标记，普通日期保持统一白色
- 数据保存在当前浏览器，无需登录
- 支持导出 / 导入 JSON 备份
- PWA：发布到 HTTPS 后可添加到手机主屏幕并离线打开

## 文件说明

- `index.html`：页面入口
- `styles.css`：界面样式
- `app.js`：计划、日期、备份和交互逻辑
- `manifest.webmanifest` / `sw.js`：手机安装与离线缓存
- `assets/`：应用图标

## 说明

计划数据只保存在当前设备的浏览器中。清除网站数据、换浏览器或更换手机之前，请先在“设置与备份”里导出备份。
